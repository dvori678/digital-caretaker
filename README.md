# אב בית דיגיטלי

מערכת לניהול בקשות תחזוקה בבית ספר. אנשי צוות (מורים, מזכירות) פותחים בקשות, למשל "להחליף נורה בכיתה ד'", ואב הבית רואה את כל הבקשות, מעדכן את הסטטוס שלהן ומוסיף הערות.

פרויקט גמר בקורס React.

## 🔗 קישורים

- **האתר:** https://digital-caretaker.onrender.com
- **השרת (API):** https://digital-caretaker-api.onrender.com

> השרת מותקן בתוכנית החינמית של Render, ו"נרדם" אחרי 15 דקות בלי שימוש. לכן ההתחברות הראשונה עשויה לקחת עד דקה.

## ✨ מה אפשר לעשות

**איש צוות**
- לפתוח בקשה חדשה: כותרת, תיאור, מיקום, קטגוריה, עדיפות ותאריך יעד
- לראות רק את הבקשות שהוא פתח
- לערוך או למחוק בקשה, כל עוד היא בסטטוס "חדשה"

**אב הבית**
- לראות את כל הבקשות
- לעדכן סטטוס (חדשה / בטיפול / טופלה) ולהוסיף הערה
- לערוך ולמחוק כל בקשה

**לכולם**
- כרטיסי סיכום: כמה בקשות יש בכל סטטוס
- חיפוש חופשי, סינון לפי סטטוס, קטגוריה ועדיפות, ומיון
- סימון בקשות שעבר תאריך היעד שלהן

## 🛠️ טכנולוגיות

**צד לקוח (`client`)**
- React + TypeScript (Vite)
- React Router: ניווט בין עמודים ונתיבים מוגנים
- React Hook Form + Zod: טפסים וולידציה
- React Query: כל הקריאות לשרת, טעינה ושגיאות
- Context: ניהול המשתמש המחובר

**צד שרת (`server`)**
- Node.js + Express
- MongoDB Atlas דרך Mongoose
- JWT להתחברות, bcryptjs להצפנת סיסמאות

**ענן:** Render (שרת ו-Static Site), MongoDB Atlas (מסד נתונים)

## 💻 הרצה במחשב

**1. השרת**

ליצור קובץ `server/.env`:
```
PORT=4000
MONGO_URI=<כתובת החיבור ל-MongoDB>
JWT_SECRET=<מחרוזת סודית ארוכה>
CLIENT_URL=http://localhost:5173
```

```
cd server
npm install
npm run seed
npm run dev
```

`npm run seed` יוצר את המשתמשים ואת הבקשות לדוגמה. **שימו לב: הוא מוחק את כל הבקשות הקיימות.**

**2. הקליינט** (בטרמינל נוסף)

ליצור קובץ `client/.env`:
```
VITE_API_URL=http://localhost:4000
```

```
cd client
npm install
npm run dev
```

ואז לפתוח את http://localhost:5173

## 🔌 API

כל הבקשות, חוץ מההתחברות, דורשות כותרת `Authorization: Bearer <token>`.

| שיטה | נתיב | מה עושה |
|---|---|---|
| `POST` | `/api/login` | התחברות. מחזיר טוקן ופרטי משתמש |
| `GET` | `/api/tasks` | רשימת בקשות, עם חיפוש, סינון ומיון |
| `GET` | `/api/tasks/:id` | בקשה אחת |
| `POST` | `/api/tasks` | יצירת בקשה |
| `PUT` | `/api/tasks/:id` | עדכון בקשה |
| `DELETE` | `/api/tasks/:id` | מחיקת בקשה |

ההרשאות נבדקות בשרת, לפי התפקיד שבטוקן.
